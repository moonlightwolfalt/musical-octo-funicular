# musical-octo-funicular

Reference copy of the page and static files served at https://v1.mope.io, plus notes on how its client works.

- `v1.mope.io/` – downloaded page, `client.js` (original) and `client.pretty.js` (formatted), CSS, `updates.json` (no images or audio)
- `MANIFEST.md` – list of asset paths the client uses (paths only)
- `NOTES.md` – WebSocket servers, packet format, and where the client loads its assets from

The page, code and art belong to their owner (mope.io / Wacka Games). This repo is for reading and analysis only.
